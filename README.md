# Corona Server

Código do servidor de Minecraft **Corona Server** (Paper 26.3 + Geyser, Java e Bedrock).

## Pastas

- `plugins/` — código-fonte dos plugins próprios (arena, backrooms, casas, clas, coronapack, defesa, extras, fabrica, hotel, lobby, loja, masmorras, naochore, poderes, slender, sons, testebot, turno, vista, vovo).
- `pacote/java` e `pacote/bedrock` — pacote de texturas (Java e Bedrock).
- `ferramentas/modelos` — scripts Python que geram modelos e texturas (trajes, asas hussardo etc.).
- `ferramentas/skins`, `ferramentas/tools` — skins e utilitários.
- `ferramentas/atalhos-desktop` — atalhos .bat usados no PC do servidor.
- `ferramentas/compilar.sh` — script de compilação dos plugins.

## Pacotes Bedrock por link

Os pacotes Bedrock são baixados pelo jsDelivr a partir do repositório público
`PauloMiguel13000/corona-pacotes`. Ao atualizar o pacote, suba o novo
`<nome>-<sha1 10>.zip` lá antes de instalar no servidor.
